## Fund (målt, tools/measure-duels.mjs)
- Fase-duellen (match.js ~l.192): opbygning PAS+BAL (gns 22,5) mod pres INT+STA·0,6
  (gns 16,2) + rnd·7 hver → opbygning vinder **96,8 %** af duellerne i fuld simulering.
  Formlen er kildens (spec §5), men er reelt en fejl: pres kan næsten aldrig vinde.
- Mod-kunnen: counterXpForMatch giver 4–16 pr. kamp på primær stil, +60 % på sekundær,
  −3 rust. En starter går fra ~45 til ~75 på 3 runder.

## Plan
1. **Opstilling i Trup** (punkt 1): Trup = klubhoved, regneark (sortering/filter/byt) i
   fuld bredde, derunder bane + bænkrække | spillerkort. Taktik uændret (bane | kort +
   formation/planer/faser/Hvis-Så). Banen findes i begge faner (samme komponent og
   samme byt-tilstand). Alternativ overvejet: slå Trup og Taktik sammen – afvist, det var
   det "rodede layout".
2. **Langsommere mod-kunnen** (punkt 2): XP pr. kamp 1–5 (i stedet for 4–16): 
   round(min/90 · (2 + 0,5·taktiske sejre + 1 ved mål)), klemt 1–5; sekundær +50 %;
   rust −1 (i stedet for −3). Mål: en fast starter +≈3/runde på primær stil, dvs. ≈40 på
   en 14-runders sæson. Spec §7 opdateres. Eksisterende værdier i gemte spil røres ikke
   (ingen migrering – brugerens tal står, de vokser bare langsommere fremover).
3. **Liga-siden** (punkt 3): under tabellen "Sidste runde (runde N)": de 4 resultater som
   knapper → åbner Kamp-fanen med netop den kamp (viewIdx). "Næste runde (runde N+1)":
   de 4 parringer fra pairRound(league, opponentIdx) – din kamp følger den valgte
   modstander (står ved ▶), med teksten "afhænger af valgt modstander".
4. **Fase-duellen balanceres** (punkt 4): pres = INT + POS·k1 + STA·k2 kalibreret så
   opbygning vinder ≈55 % ved neutrale stile (målt med measure-duels, tallet i commit).
   Referatet skrives fra DIT synspunkt, når dit hold taber duellen:
   "❌ [DIN TAKTIK VIRKER IKKE] Dine korte pasninger kører fast i X's pres …" og når dit pres
   vinder "✅ [DIT PRES VIRKER] …". Modstanderens stil navngives stadig ikke (anti-spionage).
5. Version 3.6.0, spec §5/§7/§10b, tests (unit for XP og duel-rate med seed; e2e for
   Trup-bane, Liga-resultater/næste runde, link til referat).
